# Video Converter

A simple, fast and powerful tool to convert videos into audio formats with ease.

## Features

🔄 Convert video formats (MP4, MKV, MOV, AVI, WEBM)

⚡ Fast processing using FFmpeg

## Usage

```bash
sudo mv video-converter /usr/local/bin
video-converter <file_name> <start> <stop>
```
